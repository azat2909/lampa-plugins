# Anistar

Для всех изменений в `anistar.js` используй настольную (полную) версию AniStar с шаблоном `new36` на домене, который выбран в настройках плагина. Это правило относится к каталогу, карточкам, фильтрам, поиску и их следующим страницам, авторизации, закладкам, статусам и загрузке списка серий.

Для HTML-страниц используй `desktopDocument`, для остальных запросов к AniStar используй `desktopRequest`. При проверке изменений учитывай сетевой интерфейс Android TV и переключение шаблона сайта на Tizen.
